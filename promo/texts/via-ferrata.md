# Via Ferrata Promo

## reddit

Interactive map of European Via Ferrata routes with terrain contours and ratings

Hey everyone,

I created a web tool for finding and visualizing Via Ferrata routes in Europe.

What it does:

* Interactive Route Mapping: Displays Via Ferrata routes from OpenStreetMap across Europe plotted on top of terrain data.
* Topographic Layer: Uses tiles from OpenTopoMap so you get contour lines and elevation context for the surrounding terrain.
* Difficulty Ratings: Shows route difficulties directly on the map to help filter options based on your experience level.

I'd love for you to check it out and let me know what you think: https://exploring-data.com/map/via-ferrata/

Any feedback on usability, missing areas, or features you'd like to see added would be super helpful!
